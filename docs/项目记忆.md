# Pek.RAgent 流量统计（2026-10-01 实现+冒烟验证）

## 设计总览

## weblog 要点
- 站点发现：nginx（宝塔 /www/server/panel/vhost/nginx、/etc/nginx/sites-enabled|conf.d|vhosts.d、/usr/local/nginx/conf/vhost）+ apache（sites-enabled/conf.d）；自写 token/行解析器（server 块直接子层 server_name/access_log；绝对路径判断用 `looks_like_abs_path`，勿用 `Path::is_absolute`——平台相关，Windows 测试会挂）；Windows 仅手动 WebLogs
- 行解析：combined（**第一对引号后** status bytes；nginx 转义 \x22 保证请求内无裸引号）+ Caddy JSON（行首 `{`，取 status/size/request.remote_ip）
- 增量读取：文件身份（Unix inode / Windows GetFileInformationByHandle 文件索引）+offset；首次读取 mtime=今天则从 0（补今日）否则跳尾；8MB/次；半行缓冲；轮转/截断检测
- 持久化 `Data/web_traffic.json`（30s 节流）：站点统计 + 文件 inode/offset → **重启续读不重复/不遗漏（实测）**；UV 集合不持久化（基数+新集合）
- 速率：5×1s 滑动平均；`rate_init` 首帧只建基线（防历史数据速率尖峰）

## portstat 要点
- Linux nft：独立表 `inet pek_stats`（priority -350；policy accept 只计数不动转发）；规则 comment `pek-in-tcp-80`；读取 `nft -j list table`（解析匿名 counter）；按 handle 删；**表跨重启保留**（计数不丢）；`PortTraffic` 关闭/卸载时 drop（cli.rs `cmd_uninstall` → `portstat::cleanup`）
- 端口集合：配置优先；空=监听端口（/proc/net tcp LISTEN + udp 未连接），上限 64；规则=端口×2 协议×2 方向
- 连接视图：/proc/net/*（Linux，UDP 跳过已 connect socket）；Windows GetExtendedTcpTable/UdpTable（端口字段=低 16 位 swap_bytes）
- 行数上限 150（排序后截断，防 UDP 临时端口噪音）；降级后每 5 分钟重试恢复 nft
- 速率：5s 差分
