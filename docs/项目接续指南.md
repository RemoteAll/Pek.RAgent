## 2. 项目定位与关键事实
- Pek.RAgent＝星尘代理 Rust 实现（crate `pek-ragent`；GitHub `RemoteAll/Pek.RAgent`，分支 `main`）。
- Windows 服务名 `StarAgentRust`（与 C# StarAgent 5500 并存，默认端口 **5501**）；配置 `Config/StarAgent.config`（XML，与 C# 双端互通）。
- **影子模式（默认部署模式）**：单文件程序复制到 `shadow/{名称}-{md5前8位}/` 运行；源文件不被占用，覆盖源文件 → 5s 检测 → 重建影子 → 自动重启（覆盖升级惯例）。
- **停止链**：温和（Windows `taskkill /PID /T`；Unix 组长按进程组 SIGTERM）→ 3s → 强制（`/T /F`；SIGKILL）→ 2s → 终检（`is_alive` 查 `GetExitCodeProcess`）。
- **多实例**：配置按名称 upsert（不能同名）；多实例用不同子服务名注册，各自目录/配置；停止按 PID，无同名连坐。
- 版本标记 `PEK_RAGENT_VERSION_TAG`（`Pek.RAgent/<版本>`）**禁止删除/改名**（Pek.RPanlServer 发行识别依赖）。

## 3. 构建 / 测试 / 打包
- 工具链：rustc 1.98（x86_64-pc-windows-msvc；交叉 x86_64-unknown-linux-musl 等）；edition 2024。
- 依赖（path，相对 `../`）：`dhrust=../DH.RustBase`、`pek-rcode=../Pek.RCode`、`pek-radmin=../Pek.RAdmin`——**编译报缺 API 时先拉新这三库再复测**。
- 构建：`cargo build --release`；测试：`cargo test`。
- 打包：`powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1`——**默认自动递升补丁号**（`-NoBump` 关闭；`-BumpMinor` 升次版本；版本守卫 = DH.RustBase/tools/version-guard.ps1）；`-Targets` 默认 `all`（windows + linux/arm64/riscv64/loongarch64 musl）；zig 自动发现 `E:\Soft\zig-*`（下载版本 0.17.0）。
- 产物 `dist/`：zip / tar.gz / `SHA256SUMS.txt`（**必须 LF**，Linux `sha256sum -c` 依赖）。

## 7. 变更记录（2026-10-20）：平台节点页可直达面板 + 密码状态上报

**用户原话**：「RpanelServer项目是不是在服务器节点这里增加打开Agent网页的链接。而且也看是不是可以分析判断某个节点的管理员账号密码有没有改」

- **本仓库改动**：`src/panel_ws.rs` 的 `register` 与 `heartbeat` 报文新增 4 个字段——
  `webPort`（= `LocalPort`）、`remoteAccess`（= `!LocalOnly`）、`webUser`（内置管理员用户名）、
  `defaultPassword`（复用 `webpanel::uses_default_credentials`，即用户名 `admin` 且密码 `admin`）。
  统一由 `panel_meta()` / `with_panel_meta()` 平铺拼接。
- **安全边界**：只报“是否仍为出厂凭据”这一布尔判定与用户名，**不上报密码、哈希或任何凭据**。
- **配套**：Pek.RPanlServer 的 `Panl_AgentNode` 新增 `WebPort`/`RemoteAccess`/`WebUser`/`DefaultPassword` 列，
  节点页显示「🌐 打开面板」与「账号安全」（⚠ 默认密码 / 已改密 / 未上报）。旧版 Agent 不上报 → 平台显示「未上报」，互不影响。
- **验证**：`cargo check` exit=0；`Cargo.lock` 因 path 依赖（Pek.RCode 切 `zip 9` 线）重新解析（`nix`/`typed-path`/`zip 9.0.5`），锁文件随本次改动一起保留。

## 8. 变更记录（2026-10-20）：面板登录会话持久化 + 密码不明文传输

**用户原话**：「RAent的登录是只要重启就要重新输入密码吗?这个能不能做成不要动不动的就被影响到要重新输入密码。因为这个不太可能直接用https的，那么多次输入很容易被截取」

**问题定位（三处叠加，故「动不动就要重输」）**：

1. `WebPanel` 的 `TokenStore` 是**纯内存表**，进程重启（自升级、覆盖部署、服务重启）即清空 → 全部 401；
2. 有效期写死 **24 小时**（`TokenStore::new`）；
3. 前端令牌存 **`sessionStorage`**，关浏览器/标签页即丢。

**改动（共享库 + 本仓 + 前端）**：

- **DH.RustBase**（`src/net/panel_auth.rs`，仅新增、向后兼容）：`ttl_ms()`、`clear()`、`revoke_all_except(keep)`、`touch(token)`（滑动续期：剩余不足一半才续）、`snapshot()` / `restore()`（落盘与重启恢复，容量上限 512）；新增 2 项单元测试。
- **本仓**：
  - 新增配置 `WebSessionHours`（默认 **12 小时**；`0` = 关闭持久化退回进程内 24h；上限 8760 小时；旧键 `WebSessionDays` 兼容读取并按天换算），写入 `Config/StarAgent.config` 模板与配置页；**改值需重启服务生效**（TTL 在 `WebPanel::new` 读取；重启不会掉登录）；
  - 会话落盘 `Data/panel-sessions.json`（`{version,updatedAt,sessions:[{token,expire,principal}]}`，临时文件 + rename 原子替换，Unix 0600），启动 `load_sessions()` 恢复；
  - `principal()` 命中令牌时 `touch` 续期，改动才落盘（12 小时 TTL 下约每 6 小时一次写盘）；
  - **挑战式登录**：`GET /api/loginChallenge?user=…` 下发一次性 `nonce` + 盐（内置管理员用固定虚拟盐 `staragent-builtin`，数据库用户取库中 salt），前端本地算 `SHA-256(nonce : SHA-256(salt:password))` 提交；nonce 一次性、2 分钟过期；**保留明文口令分支**（旧前端/脚本兼容）；
  - `POST /api/logoutAll`（仅内置管理员，保留当前会话）；改密码 / 改用户 / 删用户立即撤销其它（或该用户）会话；
  - 前端：令牌按「保持登录」存 `localStorage`（默认勾选）或 `sessionStorage`，启动两者兼容读取；自带纯 JS SHA-256（http 非安全上下文没有 `crypto.subtle`）；挑战接口不可用时自动回退明文；用户页新增「🚪 退出所有设备」。
- **口径**：令牌 TTL 由配置决定，**滑动续期**——期间用过面板就不掉线；会话文件等同长期凭据，权限 0600、随 `Data/` 目录归属服务账户。
- **已知取舍**：DB 用户权限快照在会话期内不随库实时变化（改用户/删用户已主动吊销）；`WebSessionHours=0` 可完全回到旧行为。

**验证（本机实跑）**：

- `cargo check --all-targets` exit=0；`cargo test`：**136 passed / 0 failed / 1 ignored**；
- DH.RustBase `cargo test --features net --lib panel_auth`：**10 passed**；
- 真实 HTTP 冒烟（临时目录 `-run` + `WebAuthLevel=Full`，改配置后重启进程）：
  `challenge code=0` / `login code=0` / `replay-nonce=401` / `wrong-password=401` /
  **`status-after-restart code=0`（重启后旧令牌仍有效）** / `session-file=True` /
  `logoutAll=0 已退出 1 个其它会话` / `other-token-after-logoutAll=401 current-token=0` / `session-count=1 version=1`；
- 前端 `node --check web/app.js` 通过；`sha256Hex` 与 Node `crypto` 对拍（`abc`/空串/NIST 向量/中文 UTF-8/1KB）一致。

**后续调整（同日）**：用户原话「默认 12小时滑动吧，」——会话保持由「天」改为「小时」粒度：配置项更名 `WebSessionHours`（默认 **12**，上限 8760），配置页/模板/前端说明同步；旧键 `WebSessionDays` 仍可读（按 ×24 换算），避免已落盘的旧配置失效。
