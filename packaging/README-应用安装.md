# 应用安装进星尘

> 目标形态：**一律在 Pek.RAgent 的 Web 面板里完成安装**（后续不再给外部提供 SSH）。
> 本目录的 `install-app.sh` 只作为“无面板/批量自动化”的兜底，不再作为主路径。

## 1. 首选：面板上传安装（无需 SSH）

「子服务」页提供两条入口，效果相同：

- **📦 上传应用包**：选择 `.zip` / `.tar.gz` / `.tgz`；
- **直接拖拽**：把发布包拖到「子服务」页任意位置。

服务端自动完成：按魔数解压 → 顶层目录下沉 → 识别主程序（含 C# 的 `*.runtimeconfig.json` 配套
`*.dll`、`*.jar`）→ 跨平台校验 → 覆盖复制到工作目录（默认 `{Agent目录}/../apps/{名称}`）→
按**影子模式**注册子服务并启动。

- **包内不需要任何安装脚本**：`install.sh` / `install.ps1` 既不执行、也不参与主程序识别；
- **升级 = 重复上传同名包**：文件覆盖后自动重启（旧影子目录自动清理）；
- 需要启动参数/环境变量/健康检查时，装完在「子服务」里编辑即可。

> 注意：影子模式只复制**主程序单文件**做运行副本。C# 框架依赖包（`App.dll` + 依赖）请用
> 自包含单文件发布，或上传后把该服务部署模式改为 `Standard`。

## 2. 从 C# 版星尘迁移（面板一键）

C# 版星尘将逐步下线，存量节点不用手工重建配置：

1. 「子服务」页 → **🔄 迁移 C# 星尘**（检测到源时会自动显示提示横幅）；
2. 填写/确认源安装目录（留空自动探测常见路径）→「扫描」预览子服务清单；
3. 勾选要迁移的条目 →「开始迁移」。

服务端按顺序执行：**停 C# 子服务**（本机 UDP RPC，与 C# 面板同一契约）→ **停止并禁用 C# 星尘
系统服务**（防重启/守护再拉起）→ **导入配置**（相对路径按 C# 安装目录绝对化，程序与数据都留在
原目录，只是“换人守护”）→ **启动**启用状态的条目。

- 不改动 C# 的配置文件，也不搬动应用文件；
- C# 未运行/RPC 不通时只告警，仍会继续导入并停服；残留进程按可执行文件路径兜底结束；
- 源目录就是当前 Pek.RAgent 安装目录时直接拒绝；C# 服务名与当前服务名相同则跳过停服（防停掉自己）。

## 3. 兜底：`install-app.sh`（仅 Linux，无面板/批量场景）

```bash
sudo sh install-app.sh --name myapp --bin ./myapp --dir /opt/myapp \
     --args "urls=http://*:8080" --health http://127.0.0.1:8080/ping
sudo sh install-app.sh --name myapp --unregister   # 从星尘注销（保留文件）
```

脚本流程：文件就位 → 停旧实例 → `-AddService` 注册（注册即启用并拉起）→ 就绪检查。
星尘探测顺序：`--agent-exe` → systemd 单元（`StarAgentRust`）→ 运行中进程（`pek-ragent`）→
常见安装路径。

**C# 版星尘不再支持**：脚本检测到非 Rust 版时只打印提示，请改用面板「🔄 迁移 C# 星尘」。
